# Бой под небом

Страницы-просмотрщики для программы «Джйотиш»: бои героев и карточки героев, рассчитанные по джйотишу.

- `index.html` — бой: ссылка вида `…/boi-pod-nebom/#<номер gist>`
- `geroi.html` — герой: ссылка вида `…/boi-pod-nebom/geroi.html#<номер gist>`
- `kniga.html` — книга героя (миф по главам): ссылка вида `…/boi-pod-nebom/kniga.html#<номер gist>`

Сами бои, герои и книги лежат в секретных gist, страницы только показывают их. Дат рождения в них нет.
